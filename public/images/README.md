# Εικόνες

Τα SVG εδώ είναι προσωρινά γραφικά, όχι φωτογραφίες. Για να μπουν οι
πραγματικές, ρίξε τα αρχεία σου με τα ίδια ονόματα και άλλαξε την κατάληξη
στο `src/data/content.ts`:

| Αρχείο           | Πού μπαίνει                | Αναλογία |
| ---------------- | -------------------------- | -------- |
| `hero.*`         | δεξιά στο hero             | 4:5      |
| `remote.*`       | πακέτο Remote              | 3:2      |
| `production.*`   | πακέτο Content Production  | 3:2      |

Προτίμησε JPG στα 1600px πλάτος. Οι φωτογραφίες κόβονται με `object-cover`,
οπότε κράτα το θέμα κοντά στο κέντρο.
